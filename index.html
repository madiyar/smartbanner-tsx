smartbanner-tsxSmart App Banner for React

Promote your iOS and Android apps on your mobile website with a native-looking banner. Tiny, SSR-safe and easy to restyle.

Tiny

About 2.5 KB gzipped with zero runtime dependencies. React is the only peer.

SSR-safe

Hydration-safe and ships with “use client” for the Next.js App Router.

Easy to theme

Restyle with CSS variables, or render your own markup with a hook.

Typed

Written in TypeScript. Props, translations and the hook are fully typed.

Getting started#

The banner shows on Android and on iOS browsers that don't have Apple's native Smart App Banner (Chrome, Firefox, in-app browsers). It stays hidden in installed PWAs and after the user closes it.

Installation#

React 18 or 19 is the only peer dependency.

npm install smartbanner-tsx

Add your app details#

Put your App Store and Google Play IDs in meta tags, like for Apple's own banner. The icon is taken from apple-touch-icon.

index.html
<head>
  <meta name="apple-itunes-app" content="app-id=544007664" />
  <meta name="google-play-app" content="app-id=com.google.android.youtube" />
  <link rel="apple-touch-icon" href="/icon.png" />
</head>

Render the banner#

App.tsx
import { SmartBanner } from "smartbanner-tsx";
import "smartbanner-tsx/style.css";

export function App() {
  return <SmartBanner title="YouTube" author="Google LLC" />;
}

No meta tags?

Pass the app IDs and icon as props instead. Props win over meta tags when both are set.

App.tsx
<SmartBanner
  title="YouTube"
  appId={{ ios: "544007664", android: "com.google.android.youtube" }}
  icon="/icon.png"
/>

Customization#

Start with props, restyle with CSS variables, or take over the markup completely.

Props and translations#

Set texts, icon, links and placement. Missing translation keys fall back to English.

App.tsx
<SmartBanner
  title="YouTube"
  placement="bottom"
  className="my-banner"
  translations={{ button: "Open", price_ios: "GET" }}
  onInstall={(platform) => track("app_banner_install", platform)}
/>

CSS variables#

Override variables globally, per platform with .smartbanner-ios or .smartbanner-android, or inline with the style prop.

styles.css
/* Everywhere */
:root {
  --smartbanner-button-bg: #e11d48;
  --smartbanner-button-radius: 8px;
}

/* Only on Android */
.smartbanner-android {
  --smartbanner-bg: #202124;
  --smartbanner-title-color: #ffffff;
}

Headless hook#

useSmartBanner() gives you device detection, store links and the cookie logic. You render whatever you like.

MyBanner.tsx
import { useSmartBanner } from "smartbanner-tsx";

export function MyBanner() {
  const banner = useSmartBanner({
    appId: { ios: "544007664", android: "com.google.android.youtube" },
  });

  if (!banner.visible) return null;

  return (
    <div className="my-banner">
      <img src={banner.icon} alt="" />
      <span>{banner.description}</span>
      <a href={banner.link} onClick={banner.install}>{banner.t.button}</a>
      <button onClick={banner.close}>{banner.t.close}</button>
    </div>
  );
}

API#

All props are optional. The same options, except layout props, work with useSmartBanner().

Utilities#

  • resetSmartBanner() clears the “closed” and “installed” cookies, so the banner can show again.
  • detectDevice() and resolvePlatform() are the device detection the banner uses.

Migrating to v2#

v2 keeps the props, meta tags, class names and markup of v1. The visible change is the new default look. To keep the v1 look, change one import:

App.tsx
// v1
import "smartbanner-tsx/dist/style.css";

// v2, keeping the v1 look
import "smartbanner-tsx/classic.css";
  • ua-parser-js and js-cookie are no longer dependencies. Install them yourself only if your own code imports them.
  • The <html> margin classes are added only while the banner is visible, and removed on unmount.
  • Cookie names are unchanged, so users who closed the banner in v1 won't see it again early.

FAQ#

Why don't I see the banner on my iPhone in Safari?

Safari on iOS shows Apple's native Smart App Banner from the apple-itunes-app meta tag, so this banner is skipped there to avoid two banners. It shows in Chrome, Firefox and in-app browsers on iOS, and on Android. Set ignoreIosVersion to show it in Safari too.

Why doesn't the banner show on desktop?

It only targets phones and tablets. Use the force prop (force="ios" or force="android") to preview it on desktop.

I closed the banner and it doesn't come back. How do I test it again?

Closing sets the smartbanner-closed cookie for daysHidden days, and tapping the button sets smartbanner-installed for daysReminder days. Call resetSmartBanner() or delete these cookies.

Does it work with Next.js, Remix or other SSR frameworks?

Yes. Nothing is rendered on the server, everything is read after mount, and the package ships with "use client", so you can render it from a Next.js App Router layout.

Can I use my own design?

Yes. Restyle the default banner with CSS variables and class names, or use the useSmartBanner() hook and render your own markup.

How is it different from react-smartbanner?

smartbanner-tsx is written in TypeScript, has no runtime dependencies, supports React 18 and 19, is SSR-safe and offers CSS variables and a headless hook.
